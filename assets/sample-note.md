# Afterglow Reading Room

Afterglow is a **quiet workspace** for focused reading, thoughtful writing, and clear navigation. Its visual language keeps long-form text calm while interactive details remain easy to find.

## A Shared Palette

Pastel Archive and Ultraviolet Library use the same color families in different moods. The light mode feels *soft and archival*, while the dark mode brings restrained energy to links, tabs, and focus states.

- Clear typographic hierarchy
- Coordinated light and dark modes
- Focused accents for interactive elements
